# Sieged Empires mrpack

Modrinth/Prism Launcher pack export for **Sieged Empires 1.0.1**.

## Download

Clone this repo (Git LFS required) or download `Sieged Empires 1.0.1.mrpack` from the [latest release](https://github.com/AlbertMerle/sieged-empires-mrpack/releases).

## Install (Prism Launcher / Modrinth)

1. Open Prism Launcher (or Modrinth App).
2. **Add instance** → **Import from zip** / **Import mrpack**.
3. Select `Sieged Empires 1.0.1.mrpack`.

Pack version **1.0.1** · Fabric **26.2**
